💰 Personal Expense Tracker

A Python-based Personal Expense Tracker designed to help users manage their daily expenses and monitor their spending habits.

✨ Features

- Add daily expenses
- View all recorded expenses
- Calculate total spending
- Track remaining budget
- Organize expenses by category
- Simple menu-driven interface

🛠️ Technologies Used

- Python
- Lists and Dictionaries
- Functions
- Loops
- Conditional Statements

🎯 Project Objective

The main objective is to practice Python programming concepts by developing a practical real-world expense management application.

👩‍💻 Author

Created as a beginner Python project to improve programming and problem-solving skills.

🚀 Future Improvements

- Save expenses in CSV files
- Add monthly expense reports
- Generate spending charts
- Build a graphical dashboard
